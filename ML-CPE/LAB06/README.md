# LAB - Neural Network Classification (Calories Burned Dataset)

โปรเจกต์นี้เป็นการทดลองพัฒนาระบบ Machine Learning ด้วยอัลกอริทึม **Neural Network (โครงข่ายประสาทเทียม)** เพื่อจำแนกประเภทข้อมูล (Classification) บนชุดข้อมูล Calories Burned Dataset โดยปรับปรุงโครงสร้างโค้ดให้พร้อมสำหรับการนำไปใช้งานจริง (Production-ready) ด้วยการบันทึกสถานะของโมเดลและข้อมูลที่จำเป็น

Dataset ที่ใช้มาจาก Kaggle: https://www.kaggle.com/competitions/f-1-racer-diet-planning

---

## 1. โครงสร้างโปรเจกต์

ระบบถูกออกแบบให้ทำงานแบบแยกส่วน (Modular) เพื่อความสะดวกในการอ่าน จัดการ และนำไปต่อยอด:

- `main.py`: ไฟล์รันหลักที่เรียกใช้งาน Pipeline ทั้งหมด ตั้งแต่ต้นจนถึงการบันทึกไฟล์
- `data_loader.py`: โหลดชุดข้อมูลจากไฟล์ `train.csv` และจัดการพาธ (Path) แบบอัตโนมัติ
- `preprocessing.py`: ทำความสะอาดข้อมูล แปลงคลาสเป้าหมายเป็นตัวเลข และทำ Standardization
- `split_data.py`: แบ่งข้อมูลออกเป็นชุดสำหรับฝึกสอน (Train) และชุดทดสอบ (Test)
- `nn_model.py`: สร้างและฝึกสอนโมเดล Multi-Layer Perceptron (MLP)
- `evaluate.py`: ประเมินความแม่นยำ (Accuracy) และบันทึกรูปภาพ Confusion Matrix
- `test_nn.py`: สคริปต์เสริมสำหรับโหลดโมเดลที่ฝึกสอนเสร็จแล้ว (Pre-trained) มาทำนายข้อมูลชุดใหม่
- `outputs/`: โฟลเดอร์สำหรับจัดเก็บไฟล์ที่ระบบสร้างขึ้นทั้งหมด (ภาพกราฟ, ไฟล์ `.pkl`, `.npy`, `.json`)
- `train.csv`: ไฟล์ชุดข้อมูลต้นฉบับ (ต้องนำมาวางไว้ในโฟลเดอร์หลัก)

---

## 2. Dataset ที่ใช้

ไฟล์ข้อมูลที่เลือกใช้คือ `train.csv` (ข้อมูลอัตราการเผาผลาญแคลอรีและการออกกำลังกาย):
- **Target:** คอลัมน์ `Sex` (จำแนกเพศ: `0 = female`, `1 = male`)
- **Features:** ปัจจัยทางสรีระ ได้แก่ `Age`, `Height`, `Weight`, `Duration`, `Heart_Rate`, `Body_Temp`, `Calories`
- **Sampling:** ข้อมูลถูกสุ่มดึงมาใช้งานจำนวน 5,000 แถว เพื่อลดระยะเวลาในการประมวลผลของเครื่องคอมพิวเตอร์ แต่ยังคงประสิทธิภาพในการเรียนรู้ของโมเดลไว้

---

## 3. วัตถุประสงค์ (Objectives)

1. เพื่อเรียนรู้และประยุกต์ใช้อัลกอริทึม **Neural Network (MLPClassifier)** ในงาน Classification
2. เพื่อทำความเข้าใจความสำคัญของการทำสเกลข้อมูล (Standardization) ที่ส่งผลต่อประสิทธิภาพของ Neural Network
3. เพื่อเรียนรู้วิธีการบันทึกโมเดล (Model Persistence) และอ็อบเจกต์ต่างๆ เช่น Scaler ให้อยู่ในรูปของไฟล์ `.pkl` เพื่อนำไปใช้งานซ้ำโดยไม่ต้องฝึกสอนใหม่

---

## 4. กระบวนการทำงาน (Workflow)

1. **Data Loading:** โหลดข้อมูล `train.csv` และลบคอลัมน์ที่ไม่ส่งผลต่อการทำนาย (`id`)
2. **Preprocessing:** แปลงข้อมูลเพศให้อยู่ในรูปตัวเลข (0 และ 1) จากนั้นแยก Features และ Target
3. **Standardization:** ปรับสเกลของ Features ให้มีค่าเฉลี่ยเป็น 0 และส่วนเบี่ยงเบนมาตรฐานเป็น 1 ด้วย `StandardScaler`
4. **Data Splitting:** แบ่งข้อมูลออกเป็น Train (80%) และ Test (20%)
5. **Saving States:** บันทึกชุดข้อมูลทั้งหมดเป็นไฟล์ `.npy`, อ้างอิงคลาสเป็น `.json`, และตัวสเกลข้อมูลเป็น `.pkl` ลงในโฟลเดอร์ `outputs/`
6. **Model Training:** ฝึกสอนโมเดล Neural Network ด้วยโครงสร้าง 2 ชั้นซ่อน (Hidden Layers: 64 และ 32 โหนด)
7. **Evaluation & Export:** ประเมินความแม่นยำ สร้างกราฟ Confusion Matrix และบันทึกไฟล์โมเดลที่เทรนเสร็จแล้ว (`nn_model.pkl`)

---

## 5. คำอธิบายสั้น ๆ ของเทคนิคที่ใช้

- **Neural Network (Multi-Layer Perceptron - MLP):** 
  อัลกอริทึมที่จำลองการทำงานของโครงข่ายประสาทในสมองมนุษย์ ประกอบด้วยชั้นรับข้อมูล (Input Layer), ชั้นซ่อน (Hidden Layers) เพื่อคำนวณความซับซ้อนแบบ Non-linear, และชั้นส่งออก (Output Layer) เพื่อทำนายผลลัพธ์
- **ReLU Activation Function:**
  ฟังก์ชันกระตุ้นที่โมเดลนี้เลือกใช้ เพื่อช่วยให้โครงข่ายสามารถเรียนรู้รูปแบบที่ซับซ้อนได้อย่างรวดเร็วและแก้ปัญหาค่าความชันหายไป (Vanishing Gradient)
- **Model Persistence (joblib):** 
  เทคนิคการแปลงอ็อบเจกต์ในหน่วยความจำของ Python (เช่น โมเดล, Scaler) ให้อยู่ในรูปไฟล์ (Serialization) เพื่อให้สามารถดึงกลับมาใช้ทำนายข้อมูลใหม่ได้ทันที
