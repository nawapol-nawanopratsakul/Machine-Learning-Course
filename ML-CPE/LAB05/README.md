# LAB 05 - Support Vector Machine (SVM): Classification

โปรเจกต์นี้เป็นการพัฒนาระบบ Machine Learning ด้วยอัลกอริทึม Support Vector Machine (SVM) บนชุดข้อมูล Calories Burned Dataset (`train.csv`) เพื่อประยุกต์ใช้งานด้านการจำแนกประเภทข้อมูล (Classification)

Dataset ที่ใช้มาจาก Kaggle: https://www.kaggle.com/competitions/f-1-racer-diet-planning

---

## 1. โครงสร้างโปรเจกต์

ระบบถูกออกแบบให้ทำงานแบบแยกส่วน (Modular) เพื่อความสะดวกในการจัดการตามกระบวนการ Machine Learning:

- `main.py`: สคริปต์หลักที่เรียกใช้งานทุกขั้นตอนและประมวลผลโมเดลทั้งหมด
- `data_load.py`: โหลดชุดข้อมูลจากไฟล์ต้นฉบับ
- `preprocess.py`: ทำความสะอาด แปลงค่าเป้าหมาย และปรับสเกลข้อมูล (Standardization)
- `split_data.py`: แบ่งข้อมูลออกเป็นชุดสำหรับฝึกสอน (Train) และชุดทดสอบ (Test)
- `svm_model.py`: สร้างโมเดล SVM และกำหนดประเภทของ Kernel
- `evaluate.py`: ประเมินความแม่นยำ (Accuracy) และบันทึกกราฟ Confusion Matrix
- `test_svm.py`: สคริปต์เสริมสำหรับจำลองการป้อนข้อมูลใหม่ให้โมเดลทำนายผล (Predicting)
- `output/`: โฟลเดอร์สำหรับจัดเก็บไฟล์กราฟผลลัพธ์
- `train.csv`: ไฟล์ชุดข้อมูลต้นฉบับ

---

## 2. Dataset ที่ใช้

ไฟล์ข้อมูลที่เลือกใช้คือ `train.csv` (ข้อมูลการเผาผลาญแคลอรีและการออกกำลังกาย):

- **Target:** คอลัมน์ `Sex` (จำแนกเพศ ชาย/หญิง)
- **Features:** `Age`, `Height`, `Weight`, `Duration`, `Heart_Rate`, `Body_Temp`, `Calories`
- **การจัดการข้อมูล:** มีการสุ่มข้อมูลตัวอย่าง (Sample) จำนวน 5,000 แถว เพื่อลดทรัพยากรที่ใช้ในการคำนวณและทำให้สามารถเปรียบเทียบโมเดลได้รวดเร็วขึ้น

---

## 3. วัตถุประสงค์ (Objectives)

- เพื่อประยุกต์ใช้อัลกอริทึม Support Vector Machine (SVM) ในการจำแนกประเภทของชุดข้อมูล (Classification)
- เพื่อเปรียบเทียบประสิทธิภาพการทำงาน (Performance) ของโมเดล SVM เมื่อใช้ฟังก์ชัน Kernel แบบต่างๆ
- เพื่อนำข้อมูลนำเข้า (Input features) มาปรับให้เป็นมาตรฐาน (Standardize) ก่อนการฝึกสอนโมเดล

---

## 4. กระบวนการทำงาน (Workflow)

1. โหลดข้อมูล `train.csv` และลบคอลัมน์ที่ไม่จำเป็น (เช่น `id`)
2. แบ่งพาร์ทิชันข้อมูล (Data Partition) ให้พร้อมสำหรับการทำงาน
3. แปลงค่าเป้าหมายและทำ **Standardization** ให้กับ Input Features เพื่อให้มีมาตราส่วนเดียวกัน ซึ่งเป็นสิ่งที่จำเป็นมากสำหรับ SVM
4. ฝึกสอนโมเดล (Train SVM models) โดยทดสอบการใช้ Kernel 3 รูปแบบ ได้แก่ Linear, Polynomial และ RBF
5. ประเมินผลความแม่นยำของแต่ละโมเดล (Accuracy scores)
6. ทดลองนำโมเดลไปทำนายผล (Predictions) กับข้อมูลที่กำหนดขึ้นมาใหม่

---

## 5. เทคนิคและฟังก์ชันที่ใช้ใน SVM

SVM ทำงานโดยการหาเส้นแบ่ง (Hyperplane) ที่สามารถแยกข้อมูลต่างคลาสออกจากกัน โดยพยายามหาระยะขอบที่กว้างที่สุด (Maximum Margin)ฟังก์ชัน Kernel ที่ใช้เปรียบเทียบในแล็บนี้ ได้แก่:

- **Linear Kernel:** เหมาะสำหรับชุดข้อมูลแบบ Linear Separable Data ที่สามารถขีดเส้นตรงแบ่งขอบเขตได้ชัดเจน
- **Polynomial Kernel:** ใช้สร้างเส้นแบ่งขอบเขตแบบเส้นโค้งโพลิโนเมียล
- **RBF (Radial Basis Function) Kernel:** เป็น Kernel Trick ที่ใช้จัดการกับข้อมูลที่มีความซับซ้อนสูง (Non-linear Data) โดยช่วยจำลองข้อมูลไปสู่มิติที่สูงขึ้นเพื่อให้สามารถขีดเส้นแบ่งได้

_(หมายเหตุ: ประสิทธิภาพของโมเดลยังสามารถปรับแต่งเพิ่มเติมได้ผ่าน Hyperparameters เช่น ค่า C (Regularization) และค่า Gamma)_

---

## 6. ผลลัพธ์ที่ได้ (Output)

เมื่อรันกระบวนการทั้งหมด จะได้ผลลัพธ์ดังนี้:

1. **Accuracy Scores:** ค่าความแม่นยำของโมเดล SVM ในแต่ละ Kernel (Linear, Poly, RBF) แสดงผลบนหน้าจอ Terminal
2. **Confusion Matrix:** ไฟล์รูปภาพ `cm_linear.png`, `cm_poly.png`, และ `cm_rbf.png` บันทึกในโฟลเดอร์ `output/` แสดงความถูกต้องและผิดพลาดในการทำนาย
3. **Predictions:** ผลการทำนายข้อมูลชุดใหม่ แสดงคลาสที่โมเดลตัดสินใจเลือกผ่านการทำงานของไฟล์ `test_svm.py`
