# LAB 08 - Deep Convolutional Neural Network (DCNN) Classification

โปรเจกต์นี้เป็นการทดลองพัฒนาระบบ Deep Learning ด้วยอัลกอริทึม Deep Convolutional Neural Network (DCNN) แบบ 1 มิติ (1D) เพื่อจำแนกประเภทข้อมูล (Classification) เพศชาย/หญิง จากข้อมูลทางสรีระและพฤติกรรมการออกกำลังกาย โดยเน้นการเปรียบเทียบประสิทธิภาพระหว่างโครงสร้างเครือข่ายแบบตื้น (Shallow) และแบบลึก (Deep) พร้อมปรับปรุงโครงสร้างโค้ดให้พร้อมสำหรับการนำไปใช้งานจริง (Production-ready) ด้วยการบันทึกสถานะของโมเดลและข้อมูลที่จำเป็น

Dataset ที่ใช้มาจาก Kaggle: https://www.kaggle.com/competitions/f-1-racer-diet-planning

---

### 1. โครงสร้างโปรเจกต์

ระบบถูกออกแบบให้ทำงานแบบแยกส่วน (Modular) เพื่อความสะดวกในการอ่าน จัดการ และนำไปต่อยอด:

*   `main.py` : ไฟล์หลักที่เรียกใช้งาน Pipeline ทั้งหมด ตั้งแต่ต้นจนถึงการบันทึกไฟล์
*   `data_loader.py` : โหลดชุดข้อมูลจากไฟล์ `train.csv` และจัดการพาธ (Path) แบบอัตโนมัติ
*   `preprocessing.py` : ทำความสะอาดข้อมูล แปลงคลาสเป้าหมายเป็นตัวเลข, ทำ Standardization และ **Reshape** ข้อมูลเป็น 3 มิติ
*   `split_data.py` : แบ่งข้อมูลออกเป็นชุดสำหรับฝึกสอน (Train) และชุดทดสอบ (Test)
*   `dcnn_model.py` : สร้างและฝึกสอนโมเดล 1D Convolutional Neural Network ทั้งแบบ 1 ชั้น (Shallow) และ 4 ชั้น (Deep)
*   `evaluate.py` : ประเมินความแม่นยำ (Accuracy) และบันทึกรูปภาพประเมินผลรวมถึงกราฟสไตล์เปเปอร์วิจัย
*   `test_dcnn.py` : สคริปต์เสริมสำหรับโหลดโมเดลที่ฝึกสอนเสร็จแล้ว (Pre-trained) มาทำนายข้อมูลชุดใหม่
*   `outputs/` : โฟลเดอร์สำหรับจัดเก็บไฟล์ที่ระบบสร้างขึ้นทั้งหมด (ภาพกราฟ, ภาพ Confusion Matrix, ไฟล์ `.pkl`, `.keras`)
*   `train.csv` : ไฟล์ชุดข้อมูลต้นฉบับ (ต้องนำมาวางไว้ในโฟลเดอร์หลัก)

---

### 2. Dataset ที่ใช้

ไฟล์ข้อมูลที่เลือกใช้คือ `train.csv` (ข้อมูลอัตราการเผาผลาญแคลอรีและการออกกำลังกาย):

*   **Target:** คอลัมน์ `Sex` (จำแนกเพศ: `0 = female`, `1 = male`)
*   **Features:** ปัจจัยทางสรีระ ได้แก่ `Age`, `Height`, `Weight`, `Duration`, `Heart_Rate`, `Body_Temp`, `Calories`
*   **Sampling:** ข้อมูลถูกสุ่มดึงมาใช้งานจำนวน 5,000 แถว เพื่อลดระยะเวลาในการประมวลผลของเครื่องคอมพิวเตอร์ แต่ยังคงประสิทธิภาพในการเรียนรู้ของโมเดลไว้

---

### 3. วัตถุประสงค์ (Objectives)

1. เพื่อเรียนรู้และประยุกต์ใช้อัลกอริทึม Deep Learning (Deep Convolutional Neural Network) ในงาน Classification กับข้อมูลแบบตาราง (Tabular Data)
2. เพื่อเปรียบเทียบประสิทธิภาพ (Performance Comparison) ระหว่างการตั้งค่าโมเดล (Configurations) ที่ต่างกัน ทั้งโครงสร้างสถาปัตยกรรม (Shallow vs Deep) และจำนวนรอบการฝึกสอน (20 Epochs vs 50 Epochs)
3. เพื่อเรียนรู้วิธีการบันทึกโมเดล (Model Persistence) ทั้งในส่วนของ Scaler (`.pkl`) และ Deep Learning Model (`.keras`) เพื่อนำไปใช้งานซ้ำโดยไม่ต้องฝึกสอนใหม่

---

### 4. กระบวนการทำงาน (Workflow)

1. **Data Loading:** โหลดข้อมูล `train.csv` และลบคอลัมน์ที่ไม่ส่งผลต่อการทำนาย (`id`) ทิ้งไป
2. **Preprocessing:** แปลงข้อมูลเพศให้อยู่ในรูปตัวเลข (0 และ 1) จากนั้นแยก Features และ Target
3. **Standardization & Reshape:** ปรับสเกลของ Features ให้มีค่าเฉลี่ยเป็น 0 และส่วนเบี่ยงเบนมาตรฐานเป็น 1 ด้วย `StandardScaler` จากนั้นแปลงมิติข้อมูลจาก 2D เป็น 3D `(batch_size, 7, 1)` เพื่อให้เข้ากับโมเดล 1D
4. **Data Splitting:** แบ่งข้อมูลออกเป็น Train (80%) และ Test (20%) แบบ Stratified เพื่อรักษาสัดส่วนของเพศให้สมดุล
5. **Model Training & Comparison:** ทดลองฝึกสอนโมเดล 2 รูปแบบ คือ Config 1 (Shallow CNN - 1 Conv Layer, 20 Epochs) และ Config 2 (Deep CNN - 4 Conv Layers พร้อม BatchNormalization, 50 Epochs)
6. **Evaluation & Export:** ประเมินความแม่นยำ สร้างกราฟเปรียบเทียบรูปแบบงานวิจัย (Accuracy, Loss, Precision, Recall) และบันทึกไฟล์สเกลเลอร์พร้อมโมเดลที่เทรนเสร็จแล้วลงในโฟลเดอร์ `outputs/`

---

### 5. คำอธิบายสั้นๆ ของเทคนิคที่ใช้

*   **Deep Convolutional Neural Network (DCNN):** การเพิ่มความลึกของเครือข่ายประสาทเทียมด้วยการซ้อนชั้น Convolution (Conv1D) หลายชั้น เพื่อให้โมเดลสามารถเรียนรู้คุณลักษณะ (Features) ที่ซับซ้อนและเป็นนามธรรมมากขึ้น
*   **Batch Normalization:** เทคนิคการปรับค่าข้อมูลในแต่ละเลเยอร์ให้มีเสถียรภาพ ช่วยลดเวลาในการฝึกสอนและทำให้โมเดลแบบลึก (Deep Networks) สามารถเรียนรู้ได้อย่างมีประสิทธิภาพและแม่นยำขึ้น
*   **Dropout:** เทคนิคการปิดการทำงานของนิวรอนบางส่วนแบบสุ่มระหว่างการฝึกสอน เพื่อป้องกันปัญหาการจำข้อสอบ (Overfitting) ซึ่งมักเกิดขึ้นกับโมเดลที่มีความลึกและความซับซ้อนสูง
*   **Max Pooling (MaxPooling1D):** เทคนิคการลดขนาดของข้อมูล (Downsampling) โดยเลือกค่าที่มากที่สุดในแต่ละช่วงที่กำหนด เพื่อลดภาระการคำนวณและลดโอกาสเกิด Overfitting
*   **Model Persistence (Joblib & Keras):** เทคนิคการแปลงออบเจกต์ในหน่วยความจำของ Python ให้อยู่ในรูปไฟล์ (เช่น `.pkl` สำหรับ Scaler และ `.keras` สำหรับ TensorFlow Model) เพื่อให้สามารถดึงกลับมาใช้งานทำนายข้อมูลใหม่ได้ทันที
